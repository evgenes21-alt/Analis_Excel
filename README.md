## Описание
Приложение генерирует JSON-данные для веб-страниц, формирует Excel-отчеты, а также предоставляет некоторые другие сервисы.

Источником данных для анализа транзакций является Excel-файл, расположенный в папке ***\data***. 
Для отслеживания действий программы реализовано логирование в каждом модуле с использованием библиотеки ***logging***.

Проект состоит из модулей ***\src***, ***\tests***, а также некоторых вспомогательных конфигурационных файлов.

В пакете ***\src*** расположены следующие модули:
 - ***main***
 - ***views***
 - ***services***
 - ***reports***
 - ***utils***

### Модуль ***main***
Модуль является основным модулем приложения. Предназначен для координации работы и сбора информации от других вспомогательных модулей.

### Модуль ***views***
Предназначен для генерации JSON ответа для главной страницы веб-сайта на основе поступившей на вход модуля даты и времени в формате 
YYYY-MM-DD HH:MM:SS.

JSON ответ содержит:
- приветствие пользователя - «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» в зависимости от текущего времени;
- последние 4 цифры для каждой карты;
- общую сумму расходов по карте;
- кешбэк (1 рубль на каждые 100 рублей);
- топ-5 транзакций по сумме платежа (взяты только платежи, отрицательные суммы, в отчете представлены по модулю числа);
- курсы валют. Используется API https://apilayer.com/marketplace/exchangerates_data-api;
- стоимость акций из http://api.marketstack.com/v1/eod.

Данные для анализа и вывода на веб-странице — это данные с начала месяца, на который выпадает входящая дата, по входящую дату. 

Например, если дата — 20.05.2020, то данные для анализа будут в диапазоне 01.05.2020 - 20.05.2020.

Валюты и акции для отображения на веб-страницах задаются в отдельном файле пользовательских настроек ***user_settings.json***.

Шаблон файла ***user_settings.json***:
```python
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOG", "MSFT", "TSLA"]
}
```

### Модуль ***services***

В данном модуле реализован сервис по поиску транзакций, в которых имеются телефонные номера.

Для поиска используются регулярные выражения. Шаблон выражений предусматривает поиск по российским телефонным номерам.
Однако можно настроить шаблон для поиска и других форматов телефонных номеров.

На вход модуль получает сам файл транзакций, поле, по которому следует вести поиск, а также шаблон поиска.
Результатом работы модуля (функции) является JSON-ответ.

Например, такой:

### Модуль ***reports***
В модуле реализован декоратор для функции-отчета по тратам по категории, который записывает в файл результат, возвращаемый функцией, формирующей отчет.

Функция возвращает траты по заданной категории за последние три месяца (от переданной даты) в формате JSON.

Декоратор без параметра — записывает данные отчета в файл с названием по умолчанию.

Декоратор с параметром — принимает имя файла в качестве параметра.

Пример JSON-ответа:
```python
{
    "Категория": "Супермаркеты",
    "Траты за 3 месяца:": "25607.34 руб."
}
```

## Тестирование
В пакете ***\tests*** располагаются тесты к функциям. При тестировании используется библиотека ***pytest***.
Для установки наберите в консоли:
```python
poetry add pytest
```

Тесты используют фикстуры из модуля ***conftest.py***, параметризацию, а также мокирование c использованием декоратора ***patch*** из библиотеки ***unittest.mock***.

В докстрингах тестов приведены краткие описания их работы.
